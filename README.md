# Гибридная рекомендательная система книг (Goodbooks-10k): итоговый проект

Итоговый проект по рекомендательным системам (МИФИ). Продолжает [домашнее задание №1](goodbooks_recommender.ipynb): те же данные, тот же протокол разбиения, те же метрики и модели, поэтому все цифры сопоставимы с ДЗ напрямую.

**Цель.** Построить комплексную гибридную рекомендательную систему, которая объединяет классические подходы из ДЗ с нейросетевой архитектурой и работает для разных типов пользователей.

Весь проект - один ноутбук [`goodbooks_recommender_session.ipynb`](goodbooks_recommender_session.ipynb): в нём код (данные, признаки, метрики, модели, нейросеть, гибрид, сквозной пайплайн), запуск, эксперименты, графики и выводы. Ноутбук сохранён с результатами, выполнен с нуля на полных данных (~40 минут на CPU). Больше в проекте ничего запускать не нужно.

## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install "numpy<2" pandas scipy scikit-learn scikit-surprise "torch>=2.2" matplotlib seaborn jupyter
jupyter notebook goodbooks_recommender_session.ipynb      # затем Run All
```

1. Скачайте данные с [Kaggle](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k) и положите в папку `data/`: нужны `ratings.csv`, `books.csv`, `tags.csv`, `book_tags.csv` (папка в `.gitignore`).
2. Откройте ноутбук и выполните все ячейки сверху вниз. Сначала идёт блок «Код проекта» (ячейки только объявляют классы и функции), затем ячейка «Запуск» и отчёт, который вызывает этапы пайплайна по очереди.
3. Результаты (рекомендации, метрики, веса гибрида, конфигурация, время этапов) сохраняются в `artifacts/notebook_run/`.

**Запуск на других данных:** в ячейке «Запуск» поменять `DATA_DIR` на папку с CSV того же формата. Схема файлов проверяется при загрузке, а нумерация, разбиение, признаки, обучение, подбор весов и оценка выполняются заново, ничего не зашито под конкретные данные. Весь случайный выбор зафиксирован `SEED = 42`. В разделе 5 ноутбука тот же пайплайн дополнительно запускается на маленьком синтетическом наборе.

**Быстрая проверка.** Переменные окружения `RECSYS_FAST=1` и `RECSYS_DATA=<папка с маленьким набором>` переключают ноутбук на облегчённые настройки (маленькие модели, несколько секунд).

## Что реализовано (соответствие заданию)

### Базовая часть

| Этап | Что сделано | Раздел ноутбука |
|---|---|---|
| **1. Расширенные признаки** | **Пользователи:** число оценок и перцентиль активности, средняя оценка и смещение, разброс, доли лайков и дизлайков, «мейнстримность», широта вкуса, доля серий, повторяемость авторов. **Книги:** популярность, байесовская средняя, разброс и энтропия оценок («разнообразие оценок»), метаданные Goodreads, 20 тематических категорий (NMF по тегам, без ручного словаря жанров). **Взаимодействия:** близость к истории по тексту, совпадение автора и серии, тематическое сродство, разрыв популярности. Информативность признаков взаимодействия проверена по ROC AUC | 1 |
| **2. Гибрид** | Взвешенное усреднение z-скоров моделей; **разделение пользователей на новых / обычных / активных** со своими весами; единый **пул кандидатов** из top-N каждой модели; **фильтрация прочитанного**; **баланс релевантности и разнообразия** (MMR, доля «популярного» в выдаче, неперсональная выдача для пользователей без истории); доверие к коллаборативным сигналам для книг без оценок | 2 |
| **3. Оценка и оптимизация** | Сравнение гибрида с одиночными моделями и **поэтапный вклад каждой идеи** с доверительными интервалами; анализ по типам пользователей; **оптимизация весов** на val (случайные старты и локальный поиск); Precision/Recall/nDCG@K для K = 5, 10, 20, дополнительно coverage, novelty, ILD; холодный старт книг; критический анализ и выводы; графики | 3 и итоговые выводы |

### Продвинутая часть

| Что | Реализация | Раздел ноутбука |
|---|---|---|
| **Нейросетевая архитектура** | Two-Tower на PyTorch: башня пользователя строится из истории лайков (ID и текстовые эмбеддинги), башня книги - из ID, текста и признаков; обучение in-batch softmax с logQ-коррекцией, удаление целевой книги из истории, history dropout, ID dropout для работы на новых книгах | 4 |
| **Абляция** | ID / + контент / + признаки книг / + признаки пользователей / без ID | 4.3 |
| **Интеграция в гибрид** | Two-Tower - ещё одна компонента смеси и источник кандидатов в пул | 2, 4.5 |
| **Сквозной пайплайн** | Класс `Pipeline`: загрузка -> предобработка -> обучение -> подбор весов и баланса -> финальное обучение -> рекомендации -> оценка -> экспорт артефактов; перезапуск на новых данных | 5 |

## Протокол оценки

- Временных меток нет, поэтому разбиение случайное внутри каждого пользователя: train 70%, val 10%, test 20% (как в ДЗ, размеры совпадают до одной оценки).
- Релевантной считается книга с оценкой >= 4. Кандидаты - все книги, которых нет в обучающей части пользователя.
- Гиперпараметры, веса гибрида, λ и число эпох нейросети подбираются на val (модели обучены на train). Финальные модели обучаются на train+val и оцениваются на test один раз. Признаки, зависящие от оценок, считаются только по обучающей части (утечки из test нет).
- Корректность метрик проверяется в ноутбуке (раздел К8) на примерах, посчитанных вручную.

## Результаты (test, K = 10, 43 434 пользователя)

| Модель | P@10 | R@10 | nDCG@10 | ILD@10 |
|---|---|---|---|---|
| Random | 0.0004 | 0.0011 | 0.0007 | 0.88 |
| Popularity / SVD (surprise) / приор качества | ~0.0005 | ~0.0015 | ~0.001 | - |
| Content-based (TF-IDF) | 0.042 | 0.165 | 0.125 | 0.23 |
| Автор/серия (признаки взаимодействия) | 0.048 | 0.161 | 0.126 | - |
| PureSVD | 0.071 | 0.211 | 0.175 | 0.42 |
| Two-Tower (нейросеть) | 0.062 | 0.232 | 0.182 | 0.39 |
| Item-based CF (лучшая модель из ДЗ) | 0.075 | 0.251 | 0.211 | 0.49 |
| Hybrid-1: модели из ДЗ, общие веса | 0.077 | 0.257 | 0.214 | - |
| Hybrid-2: + автор/серия и приор качества | 0.077 | 0.256 | 0.213 | - |
| Hybrid-3: + веса по типам пользователей | 0.078 | 0.259 | 0.216 | 0.39 |
| Hybrid-4: + Two-Tower | 0.081 | 0.275 | 0.228 | 0.37 |
| **Итоговая система (пул кандидатов + MMR, λ = 0.7)** | **0.082** | **0.276** | **0.229** | **0.48** |

По типам пользователей (nDCG@10): новые 0.182 против 0.163 у Item-CF, обычные 0.234 против 0.219, активные 0.305 против 0.280. Лучшая одиночная модель меняется с типом: Two-Tower у новичков, Item-CF у обычных, PureSVD у активных.

**Выводы**

- Итоговая система лучше лучшей одиночной модели из ДЗ (Item-CF) на **+8.5% по nDCG@10** и **+9.8% по Recall@10**; прирост значим (95% ДИ по пользователям для nDCG@10: +0.017...+0.019).
- Основной вклад даёт нейросеть в гибриде (Hybrid-3 -> Hybrid-4: +0.011 nDCG@10), хотя сама по себе она слабее Item-CF. Веса по типам пользователей дают ещё около +0.003. Гибрид только из моделей ДЗ лучше Item-CF всего на ~1%.
- Явные признаки «автор/серия» и «приор качества» как добавка к смеси на общих весах ничего не дали (Hybrid-2 не лучше Hybrid-1). Популярное, SVD из surprise и приор качества не лучше случайной выдачи: в `ratings.csv` не больше 100 оценок на книгу. Слоты «популярного» вредят на val для всех типов, поэтому оптимальная доля - 0.
- MMR с λ = 0.7 сохраняет релевантность (nDCG@10 0.228 -> 0.229), но поднимает разнообразие выдачи (ILD 0.37 -> 0.48). λ выбрана по правилу «самое сильное разнообразие при потере nDCG на val не больше 2%».
- Абляция Two-Tower: контент даёт +10% (0.120 -> 0.133 nDCG@10 на val), признаки книг нейтральны, признаки пользователей ухудшают качество (0.121), поэтому в боевой модели выключены.
- На новых книгах без единой оценки коллаборативные модели не лучше случайных (nDCG@10 ~0.007), а контент (0.257), автор/серия (0.241) и гибрид с контентной частью нейросети (0.274) работают.

Подробный анализ (типы пользователей, вклад компонент, диверсификация, сильные и слабые стороны подходов, рекомендации по выбору моделей, ограничения) - в ноутбуке.

## Ограничения

- **Протокол.** Оценка офлайн и случайная: проверяется, угадает ли модель книги, которые пользователь в итоге оценил, а заметная часть из них - продолжения серий и книги тех же авторов, поэтому метрики выше, чем в задаче «показать что-то новое». Без временных меток возможна «утечка будущего». Для реальной системы нужны A/B-тест и метрики пользы.
- **Шум.** Доверительные интервалы учитывают только разброс по пользователям. Подбор весов использует случайные старты, и соседние запуски могут отличаться в третьем знаке nDCG@10; различия порядка 0.001-0.002 (Hybrid-2 против Hybrid-1, пул + MMR против Hybrid-4) практически малы.
- **Веса гибрида** подбираются на z-скорах разной формы, поэтому читать их буквально нельзя; в Hybrid-4 вес Two-Tower 0.74-0.94, то есть гибрид - в основном нейросеть с поправками.
- **Данные.** Потолок в 100 оценок на книгу делает признаки популярности и средней оценки почти бесполезными.
