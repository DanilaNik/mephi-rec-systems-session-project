# Гибридная рекомендательная система книг (Goodbooks-10k)

Итоговый проект по рекомендательным системам (МИФИ). Продолжает [домашнее задание №1](goodbooks_recommender.ipynb): те же данные, то же разбиение, те же метрики, поэтому цифры можно сравнивать с ДЗ напрямую.

Цель: собрать гибридную рекомендательную систему, которая объединяет классические модели из ДЗ с нейросетью и учитывает разные типы пользователей.

Весь проект находится в одном ноутбуке [`goodbooks_recommender_session.ipynb`](goodbooks_recommender_session.ipynb): код, запуск, эксперименты, графики и выводы. Ноутбук сохранён с результатами, с нуля на полных данных он выполняется около 40 минут на CPU.

## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install "numpy<2" pandas scipy scikit-learn scikit-surprise "torch>=2.2" matplotlib seaborn jupyter
jupyter notebook goodbooks_recommender_session.ipynb
```

1. Скачать данные с [Kaggle](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k) и положить в папку `data/` (нужны `ratings.csv`, `books.csv`, `tags.csv`, `book_tags.csv`).
2. Выполнить все ячейки сверху вниз. Сначала идёт блок с кодом, потом ячейка «Запуск» и отчёт.
3. Результаты (рекомендации, метрики, веса гибрида, конфигурация) сохраняются в `artifacts/notebook_run/`.

Чтобы запустить на других данных, нужно поменять `DATA_DIR` в ячейке «Запуск». В разделе 5 ноутбука пайплайн дополнительно запускается на маленьком синтетическом наборе.

## Что сделано

### Базовая часть

| Этап | Что реализовано | Раздел ноутбука |
|---|---|---|
| 1. Признаки | Пользователи: активность, средняя оценка и смещение, разброс, доли лайков и дизлайков, «мейнстримность», широта вкуса, доля серий, повторяемость авторов. Книги: популярность, байесовская средняя, разброс и энтропия оценок, метаданные Goodreads, 20 тем из тегов (NMF). Взаимодействия: близость к истории, автор и серия, тематическое сродство, разрыв популярности. Информативность признаков проверена по ROC AUC | 1 |
| 2. Гибрид | Взвешенное усреднение z-скоров моделей, свои веса для новых, обычных и активных пользователей, единый пул кандидатов, фильтрация прочитанного, MMR для баланса релевантности и разнообразия, доля популярного в выдаче, выдача для пользователей без истории | 2 |
| 3. Оценка | Сравнение с одиночными моделями, вклад каждой идеи с доверительными интервалами, анализ по типам пользователей, подбор весов на val, Precision, Recall и nDCG при K = 5, 10, 20, а также coverage, novelty, ILD, холодный старт книг, выводы | 3 и итоговые выводы |

### Продвинутая часть

| Что | Реализация | Раздел ноутбука |
|---|---|---|
| Нейросеть | Two-Tower на PyTorch: башня пользователя строится из истории лайков, башня книги из ID, текста и признаков. Обучение через in-batch softmax с logQ-коррекцией | 4 |
| Абляция | только ID, ID + контент, + признаки книг, + признаки пользователей, без ID | 4.3 |
| Интеграция | Two-Tower добавлена в смесь как ещё одна модель и как источник кандидатов в пул | 2, 4.5 |
| Пайплайн | Класс `Pipeline`: загрузка, предобработка, обучение, подбор весов, финальное обучение, рекомендации, оценка, экспорт. Можно перезапустить на новых данных | 5 |

## Как оцениваем

- Временных меток нет, поэтому разбиение случайное внутри каждого пользователя: train 70%, val 10%, test 20% (как в ДЗ).
- Релевантной считается книга с оценкой >= 4, кандидаты это книги, которых нет в обучающей части пользователя.
- Гиперпараметры, веса гибрида, λ и число эпох нейросети подбираются на val. Финальные модели обучаются на train+val и один раз оцениваются на test. Признаки по оценкам считаются только по обучающей части.
- Реализацию метрик проверяем на примерах, посчитанных вручную (раздел К8 в ноутбуке).

## Результаты (test, K = 10, 43 434 пользователя)

| Модель | P@10 | R@10 | nDCG@10 | ILD@10 |
|---|---|---|---|---|
| Random | 0.0004 | 0.0011 | 0.0007 | 0.88 |
| Popularity / SVD (surprise) / приор качества | ~0.0005 | ~0.0015 | ~0.001 | н/д |
| Content-based (TF-IDF) | 0.042 | 0.165 | 0.125 | 0.23 |
| Автор/серия | 0.048 | 0.161 | 0.126 | н/д |
| PureSVD | 0.071 | 0.211 | 0.175 | 0.42 |
| Two-Tower | 0.062 | 0.232 | 0.182 | 0.39 |
| Item-based CF (лучшая модель из ДЗ) | 0.075 | 0.251 | 0.211 | 0.49 |
| Hybrid-1: модели из ДЗ, общие веса | 0.077 | 0.257 | 0.214 | н/д |
| Hybrid-2: + автор/серия и приор качества | 0.077 | 0.256 | 0.213 | н/д |
| Hybrid-3: + веса по типам пользователей | 0.078 | 0.259 | 0.216 | 0.39 |
| Hybrid-4: + Two-Tower | 0.081 | 0.275 | 0.228 | 0.37 |
| **Итоговая система (пул кандидатов + MMR, λ = 0.7)** | **0.082** | **0.276** | **0.229** | **0.48** |

По типам пользователей (nDCG@10): новые 0.182 против 0.163 у Item-CF, обычные 0.234 против 0.219, активные 0.305 против 0.280. Лучшая одиночная модель зависит от типа: у новичков Two-Tower, у обычных Item-CF, у активных PureSVD.

Что получилось:

- Итоговая система лучше Item-CF на 8.5% по nDCG@10 и на 9.8% по Recall@10, разность значима (95% доверительный интервал для nDCG@10 от +0.017 до +0.019).
- Основной вклад даёт нейросеть в гибриде (Hybrid-3 → Hybrid-4: +0.011), хотя сама по себе она слабее Item-CF. Веса по типам пользователей дают ещё около +0.003.
- Автор/серия и приор качества как добавка к смеси ничего не дали (Hybrid-2 не лучше Hybrid-1). Popularity, SVD из surprise и приор качества не лучше случайной выдачи, потому что в `ratings.csv` не больше 100 оценок на книгу. Доля популярного в выдаче на val только вредит, поэтому выбрано 0.
- MMR с λ = 0.7 сохраняет релевантность (nDCG@10 0.228 и 0.229) и поднимает разнообразие (ILD с 0.37 до 0.48).
- Абляция Two-Tower: контент даёт +10% (0.120 → 0.133 nDCG@10 на val), признаки книг почти ничего не меняют, признаки пользователей ухудшают качество (0.121), поэтому они выключены.
- На книгах без единой оценки коллаборативные модели не лучше случайных (nDCG@10 около 0.007), а контент (0.257), автор/серия (0.241) и смесь контента с нейросетью (0.274) работают.

Подробный разбор (типы пользователей, вклад компонент, разнообразие, сильные и слабые стороны подходов) есть в ноутбуке.

## Ограничения

- Оценка офлайн и случайная: проверяем, угадает ли модель книги, которые пользователь потом оценил. Заметная часть из них это продолжения серий и книги тех же авторов, поэтому метрики выше, чем были бы в задаче «показать что-то новое». Из-за отсутствия временных меток модель может «видеть будущее» пользователя.
- Доверительные интервалы учитывают только разброс по пользователям. Подбор весов использует случайные старты, поэтому разные запуски могут отличаться в третьем знаке. Различия порядка 0.001-0.002 (Hybrid-2 и Hybrid-1, пул с MMR и Hybrid-4) малы.
- Веса гибрида получены на z-скорах, и буквально читать их нельзя. В Hybrid-4 вес Two-Tower 0.74-0.94, то есть гибрид это в основном нейросеть с поправками.
- Потолок в 100 оценок на книгу делает популярность и среднюю оценку почти бесполезными.
